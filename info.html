دليل إعداد وتشغيل نقطة الاتصال وسيرفر بايثون

الخطوة 1: تنظيف المنافذ والكارت

قم بتنفيذ الأوامر التالية في نافذة التيرمينال لإيقاف أي عمليات معلقة وإعداد كارت الواي فاي الداخلي:

sudo killall dnsmasq hostapd
sudo airmon-ng check kill
sudo rfkill unblock wlan
sudo ifconfig wlan0 down
sudo ifconfig wlan0 up
sudo ifconfig wlan0 192.168.10.1 netmask 255.255.255.0 up

الخطوة 2: تشغيل خادم التوزيع والتحويل (dnsmasq)

افتح نافذة تيرمينال جديدة داخل مجلد المشروع، ثم شغل أمر الـ DHCP والتوجيه:

sudo dnsmasq -C dnsmasq.conf -d

الخطوة 3: تشغيل نقطة الاتصال (hostapd)

افتح نافذة تيرمينال ثانية داخل مجلد المشروع، ثم شغل أمر بث الواي فاي:

sudo hostapd hostapd.conf

الخطوة 4: تشغيل سيرفر بايثون (app.py)

افتح نافذة تيرمينال ثالثة وأخيرة، ثم شغل سيرفر الفلاسك:

sudo python3 app.py
